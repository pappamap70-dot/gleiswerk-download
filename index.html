Gleisplaner für Fleischmann piccolo (Spur N) – 3D, Höhen, Probefahrt, Stützen und Laser-Schnittvorlagen

Gleiswerk N für Windows
Version 0.1.1 · Windows 10/11 · ca. 2 MB

Installieren

  1. Datei herunterladen und doppelklicken. Installiert wird nur für den eigenen Benutzer, ohne Administratorrechte.
  2. Windows SmartScreen fragt beim ersten Mal nach, weil der Installer nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
  3. Neue Versionen meldet Gleiswerk beim Start von selbst.

Arbeiten mit Dateien

  • Einmal „Speichern unter …“ – danach landet jede Änderung automatisch in dieser Datei.
  • Beim nächsten Start öffnet Gleiswerk die zuletzt benutzte Datei.
  • Sicherungskopien alle 10 Minuten unter %APPDATA%\de.pappamap.gleiswerk\sicherungen.
